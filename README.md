# ML Research Project

本仓库用于小组共同维护机器学习项目的代码、实验和数据。

## 协作规则

1. 从最新的 `main` 创建工作分支，不直接修改 `main`。
2. 完成修改后创建 Pull Request（PR）。
3. PR 必须通过自动检查，并由仓库负责人 `@SAKANA2336` 审核批准后才能合并。
4. 原始数据放在 `data/raw/<批次名称>/` 中。每次上传使用新的批次目录；已经提交的原始数据不得覆盖、删除或改名。
5. 清洗、合并和特征工程的结果放在 `data/processed/`，并保留生成这些结果的脚本。

更完整的提交步骤见 [CONTRIBUTING.md](CONTRIBUTING.md)。
