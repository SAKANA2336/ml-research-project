# MOJO 论文复现流程

## 1. 复现目标

本项目计划使用作者提供的官方代码和预训练权重，复现 MOJO 在癌症多组学数据上的一个下游任务，并完成一项规模较小、便于比较的改进实验。

由于完整预训练需要较大的计算资源和较长的训练时间，本次复现不从头训练 MOJO，而是以官方预训练模型为基础进行特征提取、下游训练和结果评估。

## 2. 获取论文资源

- [ ] 下载并阅读论文及补充材料。
- [ ] 获取官方代码仓库和预训练权重。
- [ ] 查看官方环境配置、数据处理脚本和运行说明。
- [ ] 记录论文、代码、模型权重和数据集的具体版本。

## 3. 配置运行环境

按照官方说明安装 Python、PyTorch、CUDA 及其他依赖，并完成以下检查：

- [ ] Python 环境能够正常启动。
- [ ] PyTorch 能够识别 GPU。
- [ ] 官方模型代码能够导入。
- [ ] 预训练权重能够正常加载。
- [ ] 使用少量样本完成一次前向计算。

建议保存完整的环境信息，例如 `requirements.txt`、`environment.yml` 或 `pip freeze` 输出，以便组员使用相同环境。

## 4. 准备公开数据

从 TCGA 或论文指定的数据来源获取以下数据：

- bulk RNA-seq 基因表达数据；
- DNA 甲基化数据；
- 癌症类型、生存时间和结局等临床标签。

记录数据下载地址、版本、下载日期和样本数量。原始数据应保持不变，清洗后的数据另行保存。

## 5. 匹配患者样本

使用患者编号匹配 RNA、甲基化和临床数据：

1. 统一不同文件中的患者编号格式；
2. 删除重复样本和无法匹配的记录；
3. 检查标签缺失情况；
4. 保留同时具有 RNA 和甲基化数据的患者；
5. 保存最终样本清单及每一步筛选后的样本数量。

## 6. 数据预处理

尽量使用官方脚本和论文中的参数完成以下步骤：

1. 清洗并标准化 RNA 表达值；
2. 将多个 CpG 位点聚合为基因级甲基化值；
3. 对齐两种组学共有的 17,116 个基因；
4. 将连续数值离散到 64 个区间；
5. 按照官方设置划分训练集、验证集和测试集；
6. 检查不同数据集之间是否存在患者重叠或数据泄漏。

预处理完成后，应保存处理脚本、样本列表、特征维度、数据划分和随机种子。

## 7. 加载预训练模型并提取特征

加载官方 MOJO 预训练权重，将处理后的 RNA 和甲基化数据输入模型，为每位患者生成 512 维表示。

需要检查：

- 输入基因顺序是否与官方模型一致；
- RNA 和甲基化是否使用了正确的归一化与离散化方法；
- 模型输出的样本数量和特征维度是否正确；
- 特征中是否出现 `NaN` 或无穷值。

生成的患者表示应单独保存，避免每次训练下游模型时重复运行特征提取。

## 8. 复现下游任务

建议优先复现癌症类型分类任务：

1. 将患者的 512 维 MOJO 表示输入下游分类器；
2. 使用论文相同或尽量接近的训练参数；
3. 在训练集上训练，在验证集上选择模型；
4. 仅使用测试集进行最终评估；
5. 报告 accuracy、weighted-F1 和混淆矩阵。

如果时间和数据条件允许，可以增加生存风险预测任务，并使用 C-index 作为主要评价指标。

## 9. 建立对照基线

至少实现一种简单基线，并确保它与 MOJO 使用相同的数据划分：

- 只使用 RNA 特征；
- 只使用甲基化特征；
- 分别提取两种组学特征后直接拼接；
- 使用传统机器学习分类器处理降维后的多组学特征。

基线与 MOJO 应使用一致的评价指标，避免因数据划分或指标不同而产生不公平比较。

## 10. 完成一项简单改进

在不重新进行完整预训练的前提下，选择一项范围明确的改进：

- 调整下游分类器的层数或隐藏维度；
- 调整学习率、dropout 或类别权重；
- 对 MOJO 表示进行特征选择或降维；
- 使用模态 dropout 模拟 RNA 或甲基化缺失；
- 增加简单的数据增强或类别不平衡处理。

改进实验必须保持数据划分、评价指标和训练轮数等主要条件一致，只改变需要研究的因素。

## 11. 重复实验与结果比较

使用多个随机种子重复训练，报告结果的平均值和标准差。建议整理成如下表格：

| 方法 | 输入数据 | Accuracy | Weighted-F1 | 备注 |
| --- | --- | ---: | ---: | --- |
| 基线方法 | RNA 或甲基化 | 待填写 | 待填写 | 复现实验 |
| 原始 MOJO | RNA + 甲基化 | 待填写 | 待填写 | 官方预训练权重 |
| 改进方法 | RNA + 甲基化 | 待填写 | 待填写 | 改进内容 |

如果结果与论文存在差异，应检查数据版本、预处理、样本划分、超参数、随机种子和软件环境，并在报告中说明可能原因。

## 12. 最终需要提交的材料

- [ ] 论文 PDF；
- [ ] 环境配置文件；
- [ ] 数据下载和预处理说明；
- [ ] 可重复执行的数据处理脚本；
- [ ] 基线、MOJO 和改进方法的训练代码；
- [ ] 训练日志和模型配置；
- [ ] 实验结果表格与图像；
- [ ] 复现结果、差异分析和改进结论。

## 13. 建议执行顺序

```text
配置环境
  → 获取并检查数据
  → 完成患者匹配和预处理
  → 加载官方权重并提取患者表示
  → 复现癌症类型分类任务
  → 建立简单基线
  → 实现一项小规模改进
  → 使用多个随机种子重复实验
  → 整理结果并撰写报告
```
